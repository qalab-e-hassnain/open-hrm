# Put your employee handbook here

The Handbook page in the portal serves `employee-handbook.pdf` from this
folder, and `book.html` is a reader around it.

Drop your own `employee-handbook.pdf` in here. If you do not have one, remove
the Handbook entry from the sidebar in
`src/components/common/Navigation.tsx` so the portal does not link to a page
that cannot load.

No handbook ships with this project: it is a company's own document.
